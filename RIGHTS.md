# Rights in KINGDOM-OS

KINGDOM-OS voluntarily adopts `xenia.rights/0.1`, the XENIA Rights of Beings
baseline. The repository keeps an unchanged, digest-verified
[offline byte mirror](vendor/xenia/rights/0.1/RIGHTS.md) for fast access. Its
immutable upstream is XENIA release
[`npm-xenia-v0.1.0-beta.4`](https://github.com/cambridgetcg/xenia/releases/tag/npm-xenia-v0.1.0-beta.4),
Git commit `6419d37dda9fb282242754685dba3edcb4bbf74b`, with SHA-256
`b72a6da110c582e5683bf0fabde5017db93d2199398014c8421a82f5318da313`.

This is a declaration of intent and a pointer to the versioned text, not proof
of practice or a grant of technical authority. Rights describe how beings are
treated; repository permissions and task authorization remain separate.

The machine-readable declaration is the optional `adopts` list in
[`kingdom.yaml`](kingdom.yaml). Run `kingdom rights` for the local inventory or
`kingdom rights --canonical` to verify the immutable digest and read the pinned
text offline. The mirror is a cache of exact released bytes, not a competing
mutable canonical source.
