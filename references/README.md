# Pinned protocol references

`xenia-rights-0.1.md` is an exact byte-for-byte snapshot of the normative
`RIGHTS.md` at upstream commit
`c1d685e053bd2261219d983d2ec61017f59df60c`. Its SHA-256 is
`b72a6da110c582e5683bf0fabde5017db93d2199398014c8421a82f5318da313`.
Do not edit the snapshot in place; adopt a newer baseline through an explicit
Nen protocol revision and update the manifest pins and validator together.

Relative links inside the snapshot belong to the upstream XENIA repository
and are intentionally not vendored here. Resolve them against the
[pinned upstream tree](https://github.com/cambridgetcg/xenia/tree/c1d685e053bd2261219d983d2ec61017f59df60c),
not this directory. The local snapshot is present so the rights floor remains
inspectable offline; the upstream link supplies its surrounding documents and
history.
