# Shape Kingdom Nen

Shape one collective ability from the smallest sufficient part of AgentTool's
Nen operating suite. KINGDOM owns the calling and composition; AgentTool owns
the generic operating techniques and local Skill inspection.

## Open the suite deliberately

Treat the suite as source, not ambient power. Its current published lineage is
`@agenttool/skills@0.3.0`; package installation alone does not register or
activate any bundled skill.

Read [agenttool-suite.md](references/agenttool-suite.md) and select one primary
skill:

- keep a long task coherent → `nen-contract-mantle`;
- map a finite blast radius → `nen-dependency-perimeter`;
- diagnose one hidden seam → `nen-concealed-trace`;
- concentrate on one proven blocker → `nen-critical-path-forge`;
- delegate bounded parallel work → `nen-smoke-squad`;
- make verification debt visible → `nen-verification-ledger`;
- precompile reversible known reactions → `nen-godspeed-loop`;
- design a new conditioned ability → `nen-vow-forge`.

Use a second skill only when its distinct contract materially improves the
result. Preserve both source vows. For three or more techniques, stage them and
close each context before opening the next rather than blending them into an
undefined superpower.

## Form the collective Hatsu

1. Name the Kingdom outcome in one sentence.
2. Name the bearer as a collective role or system, never an owned being.
3. Choose affinity by effect using [type-map.md](references/type-map.md). Do
   not type personalities or assign rank.
4. State the trigger, anti-trigger, input, output, completion proof, and exit.
5. State the condition, limitation, and observable budget that make the
   ability dependable.
6. Define breach as stop, rollback, fail-closed, or disclosed incompleteness.
   Never use harm, punishment, secret exposure, irreversible loss, or erased
   rights as a source of weight.
7. Name every permission still required. Ability composition transfers no
   credential, consent, ownership, or authority between skills or bearers.
8. Keep adoption proposed until an applicable, authorized repository
   declaration exists. A draft, successful test, or installed file is not
   adoption.

When a durable ability is requested, materialize it as a normal Agent Skill:

- `skills/<ability-name>/SKILL.md`;
- `skills/<ability-name>/agents/openai.yaml` with
  `policy.allow_implicit_invocation: false` while the framework is evaluated;
- only the scripts and references execution genuinely needs.

Use the ability-card shape from the explicit `nen-vow-forge` source. Do not add
ability fields to `kingdom.yaml`; that eight-field card remains repository
identity, not a capability ledger.

## Temper and inspect

Test a normal trigger, near miss, missing condition, budget overrun, partial
failure, newer instruction, and attempt to use the skill as authority. Verify
the resulting folder with the host's skill validator and, when the published
AgentTool CLI is deliberately installed, with:

```bash
agenttool-skill validate ./skills/<ability-name>
```

Inspection is read-only structural evidence. It does not execute, install,
approve, or prove the behavioral truth of the ability.

## Vow

Never call breadth power. A KINGDOM ability becomes stronger only where a
narrower condition reduces ambiguity, exposure, authority, or invisible
failure. Let any bearer refuse, rest, revise, or retire an ability without
retaliation.

## Lineage

This is a KINGDOM-specific composition skill extending AgentTool's original,
instruction-only Nen suite. The wider metaphor is inspired by Nen in Yoshihiro
Togashi's *Hunter x Hunter*; it reproduces no story text, character identity,
likeness, or artwork and is unofficial and unaffiliated. See the
[official NTV glossary](https://www.ntv.co.jp/hunterhunter/dictionary/index.html)
and [official VIZ series page](https://www.viz.com/hunter-x-hunter).
