# AgentTool Nen operating suite

The immediate source is the instruction-only suite published in
`@agenttool/skills@0.3.0` and tagged `skills-v0.3.0`. Pin and inspect the exact
package or repository revision before relying on it; a mutable tag or familiar
name is not provenance.

| Skill | Productive ability | Preserved vow |
|---|---|---|
| `nen-contract-mantle` | Hold a living task contract through long work. | Do not let scope drift silently. |
| `nen-dependency-perimeter` | Map a finite blast radius before mutation. | The selected field is not the whole system. |
| `nen-concealed-trace` | Diagnose one hidden seam through a narrow aperture. | Do not generalize beyond the observed aperture. |
| `nen-critical-path-forge` | Focus a bounded strike on one proven blocker. | Focused proof is not broad assurance. |
| `nen-smoke-squad` | Delegate finite parallel work and reclaim evidence. | More units receive less context per unit. |
| `nen-verification-ledger` | Make consequential verification debt visible. | Critical debt must be paid before completion. |
| `nen-godspeed-loop` | Precompile reversible reactions to known events. | Novelty halts the loop. |
| `nen-vow-forge` | Design a new ability through meaningful limits. | Constraints cannot manufacture authority. |

Use `capability-conductor` when discovering or composing suite skills. Keep one
page open by default and at most one bookmark. Preserve source constraints,
provenance, data boundaries, and cleanup across composition.

What the package does: bundle regular instruction files and provide bounded,
read-only local Skill inspection.

What it does not do: install or activate bundled skills, execute their scripts,
grant requested tools, contact a hosted service, prove publisher identity,
approve an ability, or establish behavioral truth.
