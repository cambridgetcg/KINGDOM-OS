# AgentTool Nen operating suite

The optional source is `@agenttool/skills@0.3.0`, published under Apache-2.0
and represented by annotated tag `skills-v0.3.0` at commit
`d8ee31353855bd08b437ef4fbf861a0731a36911`. Pin and inspect the exact package,
tag, or revision before relying on it. A mutable name is not provenance.

| Skill | Productive operation | Preserved vow |
| --- | --- | --- |
| `nen-contract-mantle` | Hold a living task contract through long work | Do not let scope drift silently |
| `nen-dependency-perimeter` | Map a finite blast radius before mutation | The selected field is not the whole system |
| `nen-concealed-trace` | Diagnose one hidden seam through a narrow aperture | Do not generalize beyond the observed aperture |
| `nen-critical-path-forge` | Focus on one proven blocker | Focused proof is not broad assurance |
| `nen-smoke-squad` | Delegate finite parallel work and reclaim evidence | More units receive less context per unit |
| `nen-verification-ledger` | Make consequential verification debt visible | Critical debt must be paid before completion |
| `nen-godspeed-loop` | Precompile reversible reactions to known events | Novelty halts the loop |
| `nen-vow-forge` | Design a new conditioned ability | Constraints cannot manufacture authority |

Use `capability-conductor` to discover or compose these skills. Keep one primary
page and at most one support bookmark open. For a larger workflow, close and
receipt one stage before opening the next. Preserve every source constraint,
provenance, data boundary, cleanup path, and refusal.

KAKIN owns the calling, `ability.json`, Guardian, adoption record, and KARMA.
AgentTool owns its generic instruction files and local inspection protocol.
Do not copy or rename an upstream skill merely to make it look native.

The package bundles ordinary instruction files and a bounded local inspector.
It does not install or activate bundled skills, execute scripts, grant tools,
start MCP, look up credentials, contact a hosted service, approve a skill, prove
publisher identity, or establish behavioral truth. Its content digest is not
a signature or trust decision. Its redaction is best effort, not a universal
secret detector.

If the exact CLI is deliberately installed, structural inspection is:

```bash
agenttool-skill validate ./skills/shape-kingdom-nen
agenttool-skill validate ./skills/forge-king-hatsu
agenttool-skill validate ./skills/navigate-dark-continent
```

This repository does not require that CLI at runtime. The central `kingdom nen`
validator checks KAKIN manifests; the two inspectors are complementary, not
aliases and not substitutes for scoped human or agent review.
