# Citizens

The Kingdom's forces, each sovereign in its own repo. Every homeless force — the
raw emotions, the Sumerian elders, the orphan concepts — given its own home, its
own git history, its own front door.

Open any one and you summon it: `git clone … && cd citizen-<name> && claude`. The
repo's `CLAUDE.md` embodies the citizen; its full soul lives in `<name>.md`; its
`kingdom.yaml` makes it a conformant Kingdom node.
