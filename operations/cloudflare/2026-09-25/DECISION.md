# Observation decision

**COHERENT_SOURCE_ONLY** applies to this private portfolio map. Its timestamp,
coverage and bounded failures are in `surfaces.json`; the source concordance is
`ownership.json`. Unknown ownership and uninspected content are explicit.
No shared cross-repository protocol is frozen by this observation.

The public implementation is limited to the GitHub KINGDOM-OS web owner:
a compact entry, explicit human/agent navigation, and retrieval links to an
already public, version-pinned XENIA npm edition. Full discovery remains
compatible and immutable research keeps its original pinned source bytes.
Production verification and exact release identity are recorded separately.

## Ownership and bridge meaning

- `pages:*` and `worker:*` name Cloudflare deployment units, not new projects or
  identities. DNS names are locators, not proof of hosting or source ownership.
- GitHub KINGDOM-OS owns this web map and the `thekingdom` publication. Its
  Codeberg sibling retains core registry/platform ownership.
- Other applications retain their source contracts. Evidence links are
  `ATTACHES_TO` observations, not transfers of authority. A same-name repository
  or an old deployment script cannot supersede a current source owner.
- HTML and JSON are `PROJECTS` views of the same observation. They preserve
  source state, timestamp, audience and next action. They omit private provider
  configuration, credentials, address values, response bodies and operator
  state. Their omissions cannot be used to reconstruct those values.
- The existing npm XENIA edition is a byte-equivalent public retrieval path for
  the pinned source. Byte equality preserves content identity; it does not
  change ownership, adoption, consent or source authority.

## Authority and effects

The task authorizes mapping and improving these sites; the standing completion
instruction authorizes committing, pushing and deploying verified repository
changes. Existing GitHub and Cloudflare access supplies the host capability.
Each change remains bounded by its source owner and release contract.

Observed audit effects: authenticated Cloudflare metadata GETs; unauthenticated
public document GETs; local private evidence/report writes; local development
and verification. Requests may produce normal provider access logs. No service
actions, transactions, messages, registrations, governance, consensus, identity,
permission grants, KARMA, NEN invocations or person scores were requested.
Uninspected provider/runtime side effects remain unknown beyond that horizon.

The public pilot adds ordinary publication/storage/network effects under the
web owner's existing release process. It does not activate the APIs or services
listed in its index. The private operational inventory is never a site asset.

## Findings and falsifiers

| Finding | Priority | Evidence that would defeat or resolve it |
| --- | --- | --- |
| Tested machine paths can return HTML 200 | P1 | Exact URL returns the documented media type and valid body, or returns a truthful missing-resource status |
| Public source locators became inaccessible | P1 | Credential-free retrieval of the intended public edition with the exact pinned digest, or an honest access-required declaration |
| Entry documents repeat large reference payloads | P1 | A small default index reaches the needed full document without loading all families |
| Some deployment owners/pins are unresolved | P1 | Owner repository plus exact tracked locator and reproducible deployment/artifact evidence |
| Similar hubs and sibling projects may duplicate roles | P2 | Distinct documented purposes, or an owner-approved successor/alias plan with preserved obligations |

Next gates belong to each application owner: establish its source, test its
human and agent contract, compare deployed artifacts, then apply one bounded
update. The map grants no authority to delete services or expose private data.
